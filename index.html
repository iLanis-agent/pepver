PepVer
Python versions do not sort the way you think. Or match the way you think.
Open the app
1.0.dev1 < 1.0a1 < 1.0rc1 < 1.0 == 1.0.0 < 1.0.post1. And >1.7 does not match 1.7.0.post1, though it is newer than 1.7.

What it does

  • Sorts a list of versions and shows each one normalized (1.1RC1 becomes 1.1rc1, 1.0-1 becomes 1.0.post1).
  • Tests them against a requirement like ~=2.2 or >=1.0,<2 and says which clause rejected each one.
  • Flags invalid versions.
  • Runs in your browser. Nothing is uploaded.

How far to trust it

  • Checked against the Python packaging library on 6000 random version strings, 8000 ordering pairs and 10000 requirement clauses, plus examples from PEP 440.
